## Getting Started

To run this project locally, follow these steps:

**1. Clone the repository**

```bash
git clone https://github.com/dntyzl/dev-portfolio-adtzy.git
```

**2. Navigate to the project directory**

```bash
cd dev-portfolio-adtzy
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

The website will be available at the local development URL provided by Vite.
